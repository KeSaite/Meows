01

A few small VPSs were already enough to make this annoying.

I used to SSH into them one by one just to see whether CPU, memory, or disk looked wrong. A lot of monitoring setups also wanted another daemon, another port, or a separate dashboard.

These are small machines, and I did not want to change the server environment just to watch it. Meows uses the SSH access that is already there and reads the usual Linux interfaces from the client.

I did not want another agent running just so I could look at the status.

02

What I use on my own servers.

Most of it came from something I kept checking or looking up, then stayed in the app.

Monitoring

When a curve looks wrong, I want the process or device beside it.

CPU, memory, disk, network, and TCP history are shown with the processes, mounts, or interfaces behind the number. Alerts are set per server; several thresholds crossing at once are merged into one notification.

  • Live cards for all of my servers
  • Processes, mounts, and interfaces under the history chart
  • Disconnect and recovery notices, with per-server thresholds

Terminal + Lens

Seeing a domain in a log and then jumping to a separate tool got old.

That is why I added Meows Lens. An IP, domain, URL, or permission string in the terminal or Docker log can be opened where it appears, then passed to DNS, WHOIS, TLS, or the permission calculator.

Nothing runs by itself. Lens shows the available action and waits for a tap.

Other tools

Docker, tunnels, and the small tools I used to search for each time.

Docker management also goes through SSH, so there is no remote API port to expose. The app also has SSH tunnels, bastion hosts, DNS, TLS, WHOIS, subnet, Cron, regex, timestamp, permission tools, and more.

03

The app stores SSH passwords and private keys. I did not want to cut corners here.

Credentials are encrypted on the device with AES-GCM and Android Keystore. Meows has no service that receives monitoring data. The only runtime permission is notifications; the rest of the app still works if it is denied.

04

My own servers do not cover all of these Linux environments.

Meows only uses SSH, so the compatibility work lands in the client. Old kernels, stripped-down systems, and less common architectures are hard to cover with the machines I own. During 1.0.154, a few people on LowEndTalk gave me real environments to test against; the metric collector and history charts were reworked there.

05

A few things people usually ask before buying.

Do I need to install anything on the server?

No. Meows reads the server over standard SSH. There is no agent, daemon, Docker image or extra port to configure.

Can it reach an internal server?

Yes. Add a bastion host and monitoring, terminal sessions and SSH tunnels can all use it.

Which Android version and languages?

Android 14 or later. The interface supports English, Simplified Chinese, Traditional Chinese, Japanese and Korean.

Is there an iOS version?

Not at the moment. Meows is a native Android app.
