01

A few small VPSs were already enough to make this annoying.

I used to SSH into them one by one just to see whether CPU, memory, or disk looked wrong. A lot of monitoring setups also wanted another daemon, another port, or a separate dashboard.

These are small machines, and I did not want to change their setup just to monitor them. Meows uses the SSH access already there and reads the system information Linux provides over that connection.

I did not want another agent running just so I could look at the status.

02

What I use on my own servers.

Each part came from something I kept checking or looking up while managing my own servers.

Monitoring

When a curve looks wrong, I want the process or device beside it.

CPU, memory, disk, network, and TCP history are shown with the processes, mounts, or interfaces behind the number. Alerts are set per server. If several thresholds are crossed at once, Meows merges them into one notification.

  • Live cards for all of my servers
  • Processes, mounts, and interfaces under the history chart
  • Disconnect and recovery notices, with per-server thresholds

Terminal + Lens

Seeing a domain in a log and then jumping to a separate tool got old.

That is why I added Meows Lens. Tap an IP address, domain, URL, or permission string in the terminal or a Docker log, then choose the matching DNS, WHOIS, TLS, or permission action.

Lens does not run a lookup, open a page, or execute a command on its own. You choose what to do.

Other tools

Docker, tunnels, and the small tools I kept looking up elsewhere.

Docker management also goes through SSH, so there is no remote API port to expose. The app also has SSH tunnels, bastion hosts, DNS, TLS, WHOIS, subnet, Cron, regex, timestamp, permission tools, and more.

03

The app stores SSH passwords and private keys. I did not want to cut corners here.

Credentials are encrypted on the device with AES-GCM and Android Keystore. Meows has no service that receives monitoring data. The only runtime permission is notifications. Declining it does not disable the rest of the app.

04

My own servers do not cover all of these Linux environments.

Because Meows only uses SSH, the Android app has to handle differences between Linux systems. I cannot cover old kernels, stripped-down systems, and uncommon architectures with the machines I own. People on LowEndTalk let me test against more real servers, which led to changes in metric collection and history charts.

I kept the names of those testers on the acknowledgements page, with a different paw avatar for each person.

05

Questions before buying.

Do I need to install anything on the server?

No. Meows reads the server over standard SSH. There is no agent, daemon, Docker image, or extra port to configure.

Can it reach an internal server?

Yes. Add a bastion host, and Meows can use it for monitoring, terminal sessions, and SSH tunnels.

Which Android version and languages?

Android 14 or later. The interface supports English, Simplified Chinese, Traditional Chinese, Japanese, and Korean.

Is there an iOS version?

Not at the moment. Meows is a native Android app.
